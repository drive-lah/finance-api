Target State — which event each engine emits, and when

Every engine emits a typed economic event at a defined point in its own state machine. One shared posting layer converts each leg to the entity's currency, generates the lines, balances, and plugs FX to 7100. The JE is born DRAFT and posts only on the marked transition. Engines never build JE lines by hand, and never post a payable they don't own.

EVENT the typed signal the engine emits · when = the trigger point in that engine's state machine out = what the posting layer does with it
