## How to read the CSV

- `gst_treatment` — the value pricing will copy verbatim into `ps_line_item_definitions` and use
  for `gst_amount_minor` (1/11 on STANDARD lines, 0 otherwise). `NON_REGISTERED_HOST` = 0 GST
  because the supplier is the (typically unregistered) host, not Drive lah.
- `category_id` — **drafted per D1 recommendation A**: legacy live `payout_entries` chart ids,
  matching what pricing already seeds structurally (damage=3, excess_mileage=10, late_return=11,
  tolls=12, cleanliness=13, fuel=14, distance→10). Codes without a confirmed legacy category are
  left blank (NULL), same as pricing's seed.
- `coa_account_code`/`coa_account_name` — the finance COA v2 account each code's money lands in,
  as **confirmation of linkage only** (the durable `finance_incident_coa_map` table per POL-114 is
  the later finance-api build; not part of this artifact).
- `confidence` + `basis` — per-row honesty. LOW rows are exactly where the operator's ruling is
  most needed.

## Known tensions and gaps (flagged, not resolved here)

1. **Gross COA vs net agent presentation.** COA v2 books GBV gross (4000-4003) with host payouts
   as COGS (5000-5003), while POL-36 rules net-agent revenue. The CSV maps to the chart as it
   exists; the presentation tension is POL-36's own noted re-presentation item, not this map's.
2. **No credit-liability account.** `CREDIT_LIABILITY` codes (`credits-applied`, `guest-credit`)
   have no dedicated account in COA v2 — drafted to 2010 Other Payables with a GAP note. Adjacent
   to the deferred XSD-B2/XSD-N account-structure work; does not gate this map.
3. **Damages-vs-supply nuance.** Damage/stolen/wear-and-tear charges are arguably damages
   (no supply → OUT_OF_SCOPE) rather than host supplies (NON_REGISTERED_HOST). Both yield 0 GST
   today, so the draft keeps the uniform NON_REGISTERED_HOST convention per POL-38 provisional;
   the semantic choice is flagged for the operator.
4. **Penalty lines (host-penalty, host-cancellation-penalty)** drafted STANDARD (cancellation
   fees are generally taxable in AU) but LOW confidence — penalty-vs-damages is an accountant
   call.
5. **POL-38 is itself provisional** — incidentals GST was explicitly left "to be finalised when
   IMS's GST treatment is designed". This map is that finalisation moment; the operator's
   approval of the incident rows supersedes POL-38's provisional status (KNOWLEDGE.md update to
   follow approval).
